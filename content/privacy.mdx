本站是一个静态个人博客，没有用户账号，也不会主动收集你的姓名、邮箱等个人信息。以下说明访问本站时可能涉及的数据。

## 访问统计

本站使用以下工具统计访问量，以了解哪些内容更受欢迎：

- **Umami**：一款注重隐私的开源统计工具，不使用 Cookie，不跟踪个人身份，只记录页面浏览量、来源、浏览器与设备类型等汇总数据。
- **Google Analytics**：由 Google 提供，可能会设置 Cookie 并收集 IP 地址、浏览器信息等数据，具体请参阅 [Google 隐私权政策](https://policies.google.com/privacy)。

如果不希望被统计，可以使用浏览器的隐私模式、开启"请勿跟踪"，或安装广告/跟踪拦截插件。

## 评论

文章评论由 [Giscus](https://giscus.app) 提供，基于 GitHub Discussions。发表评论需要登录 GitHub 账号，评论内容会公开存储在 GitHub 上，并受 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) 约束。仅浏览评论无需登录。

## 本地存储

本站会在你的浏览器本地（localStorage）保存少量偏好设置，例如界面语言、沉浸式阅读选项等。这些数据只保存在你的设备上，不会上传到任何服务器，你可以随时通过清除浏览器数据将其删除。

## 第三方链接

文章中可能包含指向其他网站的链接，这些网站的隐私做法不在本政策范围内。

## 联系

如对本政策有任何疑问，欢迎通过[关于](/about/)页面中的方式与我联系。

本政策可能会不定期更新，更新后即在本页面生效。
