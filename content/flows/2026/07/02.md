title: Fable 5 回归，但是用不起……
---
昨天，Anthropic 宣布美国政府解除 Fable 5 的出口管制，今天就恢复了 Fable 5 服务，不过在[ Anthropic 的官宣](https://www.anthropic.com/news/redeploying-fable-5)中，增加了使用期限：7 月 1 日至 7 月 7 日订阅账户可以使用，但过了 7 日，就不会在订阅计划中了，只能通过 API 购买流量使用。

今天体验了下 Fable 5, 再次感受到了性能之快，也再次感受到烧 Token 的速度。晚上我的一个任务接近完成，在提交 PR 的那一刻 Claude Code 提示五小时的使用限额到了。我想着就差提个 PR，干脆临时打开 Extra credits, 继续提交 PR 的任务，结果提交完我看仪表盘傻眼了：花了 9.11 加币。

![claude-extra-credits](/flows/claude-extra-credits.png)

7 号之后真的就用不起 Fable 了。
